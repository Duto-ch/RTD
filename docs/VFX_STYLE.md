# 스킬 이펙트 그림 규칙

> 2026-11-18 시안 작업(`docs/drafts/skill-fx/`)에서 정한 규칙. 열람: https://claude.ai/artifact/AGtasrHTd1BXJoDL6igsaN (아래쪽 '탑뷰 셀 카툰풍')
> 코드: `docs/drafts/skill-fx/topdown.py` → `sheets/<이름>.png` + `.json` (프레임·기준점·길이)

| 항목 | 규칙 | |
|---|---|---|
| 시점 | **탑뷰**. 바닥 원은 위에서 본 모양(세로 0.82배), 불꽃·연기는 위로 솟지 않고 바닥을 따라 퍼짐. 중심 = 캐릭터가 선 칸 가운데 | 확정 |
| 화풍 | **셀 채색 카툰풍** — 큰 단색 면 + 그림자 한 단계 + 하이라이트 한 단계. 1px 점·노이즈 질감 금지, 입자·선은 2px 이상 | 확정 |
| 색 | **16비트(RGB555) 기본 5색**, 필요하면 **1색 더(최대 6색)** + 투명 | 확정 |
| 색 고르기 | 역할별로 직접 고름 (불: 진홍·빨강·주황·노랑·하이라이트 / 연기 섞이면 연기 2 + 불 3). 자동 감색 금지(많은 쪽 색에 쏠림) | 확정 |
| 금지 | 그라데이션·디더링. 반투명도 금지 | 확정 |
| 외곽선 | 근흑색 금지 → **색 외곽선(셀아웃)**: 그 계열의 가장 진한 색(불 진홍, 연기·바위 짙은 보라, 잎 진초록). 테두리용 색을 따로 쓰지 않는다 | 확정 |
| 사라짐 | 투명도 대신 조각나거나 픽셀 수를 줄여서 | 현재 값 |
| 겹침 | 바닥에 깔리는 이펙트(고리·오라)는 캐릭터 뒤, 칼 궤적·낙하물은 앞 | 현재 값 |

## 등급별 겹침 규칙 (2026-11-18 사용자 결정)
| 등급 | 규칙 | 계획 (스킬 수) |
|---|---|---|
| 커먼 | 커먼끼리는 어느 정도 겹쳐도 된다 | 커먼 전용 공용 세트 약 12종 × 속성색 (160개 스킬) |
| 언커먼 | 언커먼끼리는 어느 정도 겹쳐도 된다 (커먼 세트와는 따로) | 언커먼 전용 공용 세트 약 14종, 커먼보다 한 단계 화려하게 (120개) |
| 레어 | 가급적 겹치지 않는다 | 스킬마다 전용, 같은 모양 버프만 바탕 공유 + 캐릭터 상징으로 구분 (84개 → 70~84종) |
| 유니크 | 완전히 겹치면 안 된다 | 스킬마다 완전 전용 (52종) |

## 만드는 도구
- **코드로 그리기**(`topdown.py`) — 탑뷰 모양을 정확히 잡을 수 있어 기본 방식
- **pixelfx**(PixelLab `vfx_workbench`) — 기울어진 옆 시점·1px 입자가 많아 그대로는 안 맞는다. 쓰려면 손그림(drawn) 부품만, 5색·색 외곽선으로 다시 칠할 것

## 시안 (2026-11-18)
| 스킬 | 그림 |
|---|---|
| 베로나 화염 고리 | 바깥을 향한 불꽃 혀가 달린 띠가 퍼지다 조각남 |
| 카이라 화염 회전 베기 | 칼끝이 몸 둘레를 한 바퀴 — 초승달 불꽃 궤적 |

| 엘린 잎사귀 화살비 | 목표 원 → 그림자 + 비스듬히 내려오는 화살 → 별 섬광·잎 → 깃 십자 |
