# OpenAI 이미지 API 캐릭터 시험 (2026-11-17)

`NODE_USE_ENV_PROXY=1 node tools/gen-art-openai.mjs <id...>` (gpt-image-2, medium, 1024x1024, 흰 배경 — 투명 배경은 이 모델이 지원 안 함) → `art-inbox/raw/<id>.png`

- `v1-raw.png`: 첫 프롬프트("16x16 sprite …"). 그림은 좋지만 실제 도트 격자는 캐릭터 높이 55~90px
- `v1-shrink-compare.png`: 그걸 24px·16px 로 줄이면 뭉개진다
- `v2-raw.png`: "16픽셀 높이, NES·게임보이처럼" 으로 강하게 바꾼 프롬프트 — 여전히 높이 약 45~60px (모델이 16x16 을 따르지 않음)
- `v2-ingame.png`: v2 를 perfectPixel 로 정리해 실제 전투 칸(64px)에 넣어 본 모습 (에릭·올라프·엘리아스·이졸데) — 다른 그림(4px 도트)보다 훨씬 촘촘하다

결론 대기: 촘촘한 그림을 그대로 쓸지(밀도 차이) / PixelLab 등으로 정확한 크기 / 다른 방법 — 사용자 결정

## v3: 2등신 + 두상 크기 통일 (사용자 결정 2026-11-17)
- `v3/`: STYLE_PROMPT 에 '정확히 2등신, 모든 캐릭터 같은 두상 크기' 추가 → 2등신은 따르지만 **모자·왕관이 있으면 두상이 작아진다** (`v3-head-check.png`: 같은 전체 키로 맞춰 보면 올라프·이졸데 얼굴이 작다). 모델이 머리 장식까지 같은 틀에 넣으려고 머리를 줄이기 때문
- `ref/` · `ref-compare.png`: 모자 없는 에릭을 **기준 그림**으로 같이 넘겨(images/edits) "두상 크기·도트 크기·발 위치는 기준과 똑같이, 모자는 머리 위로 더 솟게" → 두상 크기·눈높이·발 위치가 맞는다. 단 이졸데가 에릭 머리 모양을 닮아 버림 → 다음 시험: 특징 없는 회색 마네킹을 기준 그림으로

## 마네킹 기준 (채택 후보, 2026-11-17)
- 기준 그림 `art-ref/mannequin.png`: 2등신 회색 마네킹 (1024 캔버스, 16px 블록) — 두상(이마~턱)·얼굴 자리·눈높이·발 위치만 표시. 외형은 없음
- `tools/gen-art-openai.mjs` 기본값이 이 기준 그림과 함께 생성(`images/edits`, 프롬프트 `artPromptRef`)
- `mannequin/`: 4명 결과 원본 + `*-clean.png`(perfectPixel 64격자 + 흰 배경 제거). `mannequin-compare.png`: 눈높이·턱·발 선이 모두 맞고 모자·왕관은 머리 위로 솟는다. `mannequin-ingame.png`: **캔버스 기준 같은 배율**(키에 맞춰 줄이지 않음)로 전투 칸에 넣은 모습 — 두상 크기가 같다
- 주의: perfectPixel 이 찾는 격자 수는 그림마다 56~70 으로 다르다. 그래서 게임에 넣을 때는 격자 수가 아니라 원본 캔버스(1024) 기준으로 같은 배율을 쓴다
