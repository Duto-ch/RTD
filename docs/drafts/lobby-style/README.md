# 로비·전투 UI 시안 — 동화풍 플랫 일러스트 (2026-11-17)

사용자가 준 참고 이미지(숲속 영지를 내려다보는 동화풍 플랫 일러스트)의 분위기로 그린 **자체 그림**. 전부 코드(SVG)로 그렸다 — `scene.js`(나무·강·길·밭·건물 생성기), `layouts.js`(화면별 배치), `ui.css`(패널·버튼·금빛 제목).

| 파일 | 내용 |
|---|---|
| `lobby-a.png` | A 영지 지도형 (가로) — 건물이 곧 메뉴: 성탑(스킬 노드)·모집 천막(가챠)·병영(덱·장비 장착)·대장간(장비 강화)·성문(출전) |
| `lobby-a-tall.png` | A 영지 지도형 (세로) |
| `lobby-b.png` | B 야영지 + 아래 탭바 — 덱 캐릭터가 가운데 서 있고 메뉴는 아래 탭 |
| `lobby-c.png` | C 카드형 — 왼쪽 그림 창 + 오른쪽 메뉴 카드 4장 |
| `battle-1.png` | 전투 화면: 지금 도트 필드 + 새 화풍 HUD |
| `battle-2.png` | 전투 화면: 전장 주변 숲까지 새 화풍 (가운데 필드·캐릭터는 도트 그대로) |

HTML 을 브라우저로 열면 같은 화면이 나온다 (가로 1280x720, 세로 544x960). 재화 3종(명성·소환권·강화석), 등급 테두리(회색 커먼·초록 언커먼·파랑 레어·금색 유니크)는 2026-11-17 기획 논의 기준의 가안.
