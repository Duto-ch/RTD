# 스코틀랜드 민요 풍 32비트 배경음 시안 (2026-11-25, 사운드 전담)

외부 음원 없이 WebAudio 로 합성한 1분짜리 반복 배경음 3곡 — **은은하고 부드럽게**. 게임에는 아직 안 들어감.
(앞 시안 `../jrpg32/` 엔진을 넓힘: 틴 휘슬·피들·백파이프 드론(아주 옅게)·바우런 추가, 3/4·6/8 박자)

| 파일 | 곡 | 쓰임 | 박자·빠르기 | 구성 |
|---|---|---|---|---|
| `title.mp3` | 안개 낀 고원의 새벽 | 타이틀 | D장조 4/4 느린 노래, 64BPM 16마디 = 60초 | 하프 펼침 + D·A 드론으로 열고(1~2) → 틴 휘슬이 스카치 스냅 섞인 느린 선율(3~10) → 피들이 받아 마무리, 휘슬이 위에서 옅게(11~16) |
| `lobby.mp3` | 호숫가 마을의 왈츠 | 영지(로비) | G장조 3/4 왈츠, 96BPM 32마디 = 60초 | 하프 쿵-짝-짝 · 피들(1~8) → 휘슬(9~16) → 단조 쪽으로 돌아 휘슬·피들 함께 + 옅은 드론(17~24) → 휘슬 + 피들 낮게(25~32) |

- 부드럽게 만든 점: 높은 소리를 깎은 음색, 긴 잔향(2.8~3.6초), 휘슬을 너무 앞에 두지 않음, 드론·바우런은 아주 옅게
- 반복 이음매: 리버브 꼬리를 곡 앞에 겹쳐 끊김 없이 돈다
- 미리 듣기 mp3 는 듣기 편하게 +6dB 올린 것 (게임에 넣을 때는 볼륨 설정을 따름)
