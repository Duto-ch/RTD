# 스코틀랜드 민요 풍 32비트 배경음 시안 (2026-11-25, 사운드 전담)

외부 음원 없이 WebAudio 로 합성한 1분짜리 반복 배경음 3곡 — **은은하고 부드럽게**. 게임에는 아직 안 들어감.
(앞 시안 `../jrpg32/` 엔진을 넓힘: 틴 휘슬·피들·드론·바우런 추가, 3/4·6/8 박자) — **드론은 2026-11-25 백파이프 → 따뜻한 낮은 패드로 교체**(백파이프 톱니 소리가 귀에 거슬린다는 사용자 의견: 배음이 거의 없는 사인·삼각 + 천천히 숨 쉬듯 일렁임)

| 파일 | 곡 | 쓰임 | 박자·빠르기 | 구성 |
|---|---|---|---|---|
| `title.mp3` | 안개 낀 고원의 새벽 | 타이틀 | D장조 4/4 느린 노래, 64BPM 16마디 = 60초 | 하프 펼침 + 낮은 D·A 패드로 열고(1~2) → 틴 휘슬이 스카치 스냅 섞인 느린 선율(3~10) → 피들이 받아 마무리, 휘슬이 위에서 옅게(11~16) |
| `lobby.mp3` | 호숫가 마을의 왈츠 | 영지(로비) | G장조 3/4 왈츠, 96BPM 32마디 = 60초 | 하프 쿵-짝-짝 · 피들(1~8) → 휘슬(9~16) → 단조 쪽으로 돌아 휘슬·피들 함께 + 옅은 낮은 패드(17~24) → 휘슬 + 피들 낮게(25~32) |
| `game.mp3` | 바람 부는 언덕의 지그 | 게임 진행 | D장조 6/8 지그, 점4분 80 · 40마디 = 60초 | 하프·바우런 인트로(1~4) → 휘슬 A(5~12) → 피들 A + 휘슬 메아리(13~20) → B 높게, 휘슬·피들(21~28) → A 함께(29~36) → 잦아드는 마무리(37~40) |

- 부드럽게 만든 점: 높은 소리를 깎은 음색, 긴 잔향(2.8~3.6초), 휘슬을 너무 앞에 두지 않음, 낮은 패드·바우런은 아주 옅게
- 반복 이음매: 리버브 꼬리를 곡 앞에 겹쳐 끊김 없이 돈다
- 미리 듣기 mp3 는 듣기 편하게 +6dB 올린 것 (게임에 넣을 때는 볼륨 설정을 따름)
- 다시 만들기: `node docs/drafts/music/scottish/render.cjs [출력 폴더] [title,lobby,game]`

## 악기 따로 듣기 (`instruments/`, 2026-11-25)
곡에 쓰인 악기를 하나씩 약 2초(+ 잔향 꼬리) — 곡과 같은 좌우·잔향·압축, **소리 크기는 악기마다 듣기 좋게 맞춤**(곡 안에서의 크기와 다름). `sampler.mp3` 는 아래 순서로 이어 붙인 것(사이 0.4초).

| 파일 | 악기 | 곡에서 하는 일 |
|---|---|---|
| `1_whistle` | 틴 휘슬 | 주 선율 (타이틀·영지·게임) |
| `2_fiddle` | 피들 | 선율 이어받기·아래 옥타브 겹침 |
| `3_harp` | 하프 | 펼침화음·왈츠 반주 |
| `4_strings` | 현악 패드 | 옅은 화음 받침 |
| `5_drone` | 낮은 패드 | 드론 자리 (백파이프 대신, 곡 안에서는 아주 옅음) |
| `6_bass` | 베이스 | 낮은 으뜸음 |
| `7_bodhran` | 바우런(틀북) | 영지·게임 박자 |
| `8_bell` | 글로켄 | 처음·끝 반짝임 |

다시 만들기: `node docs/drafts/music/scottish/instruments.cjs [출력 폴더]`
