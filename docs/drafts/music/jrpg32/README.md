# 32비트 풍 JRPG 배경음 시안 (2026-11-22, 사운드 전담)

외부 음원 없이 WebAudio 로 합성한 1분짜리 반복 배경음 2곡. **시안 — 게임에는 아직 안 들어감.**

| 파일 | 곡 | 쓰임 | 조·빠르기 | 구성 (마디) |
|---|---|---|---|---|
| `title.mp3` | 새벽의 출정 | 타이틀·영지 | D장조 96BPM 24마디 = 60초 | 하프·글로켄 인트로(1~4) → 플루트 주제(5~12) → 금관·현악 고조 + 팀파니(13~20) → 마무리(21~24) → 처음으로 |
| `adventure.mp3` | 바람을 가르는 길 | 게임 진행(전투) | G장조 128BPM 32마디 = 60초 | 금관 찌르기 + 스네어 연타 인트로(1~4) → 행진 북 + 금관 주제(5~12) → 단조 다리, 현악 노래 + 하프(13~20) → 주제 풀편성 + 플루트(21~28) → 되돌이(29~32) |

- 악기(모두 합성): 현악 합주(톱니 3개 코러스) · 금관(필터 어택 + 비브라토) · 플루트(삼각파 + 숨소리) · 하프 · 글로켄 · 베이스 · 팀파니 · 킥·스네어·하이햇·크래시 + 스테레오 리버브(합성 임펄스 2.6초)
- 반복 이음매: 렌더할 때 리버브 꼬리를 곡 앞부분에 겹쳐 끊김 없이 돈다
- 악보·악기: `synth.js` (마디마다 8분음표 8칸 표기, 길이 검사 내장)
- 다시 만들기: `node docs/drafts/music/jrpg32/render.cjs [출력 폴더]` → WAV + MP3 (Playwright Chromium·ffmpeg)
- 렌더 시간: 이 클라우드 헤드리스 브라우저에서 곡당 35~50초 — 게임 안에서 실시간 렌더하면 느린 폰에서 부담이 클 수 있음
