# 바이킹 뿔나팔 시안 (2026-11-24, 사운드 전담)

보스 등장 소리 `audio.warHorn(level)` — 매끈한 금관 나팔(보류, `../fill/horn_*.mp3`) 대신 짐승 뿔을 부는 거친 소리.

- 거친 결: 톱니 + 좁은 펄스를 비틀고(웨이브셰이퍼) 입술 떨림처럼 31Hz 로 흔듦
- 뿔 몸통 공명: 대역 통과 '홍~'(기본음 2.2배) + 콧소리 중역(1150Hz) + 4배음, 위는 어둡게
- 숨: 처음 '후' 하고 터지고 내내 옅은 바람 소리
- 음: -5반음에서 확 치고 올라 살짝 넘쳤다 자리 잡고, 느린 흔들림·빠른 떨림, 끝에서 숨이 모자라 처짐
- 메아리(0.38초, 돌 때마다 어두워짐) + 잔향, 울리는 동안 배경음·효과음 40%
