# 포근한 카드형 UI 시안 3종 (2026-11-15, 게임 미적용)

사용자가 보여준 레퍼런스(크림색 둥근 카드 · 세이지 그린 · 잎사귀 아이콘 · 부드러운 세리프 제목)의 **분위기만** 우리 게임에 옮긴 정적 시안.
레퍼런스 속 다른 게임의 캐릭터·로고·화면 구성은 쓰지 않았다. 게임 화면 그림은 가로 배치 수정안(`preview/landscape`)·세로 배치에서 UI 를 끄고 찍은 것.

| 시안 | 파일 | 구성 |
|---|---|---|
| A. 숲속 사령부 (대시보드형) | `a-sidebar-dashboard.png` | 왼쪽 짙은 숲색 메뉴(나무 간판 제목·전투/용병단/유물/명성 강화/도감/설정·오늘의 팁) + 인사 머리띠·웨이브 숫자 칩 + 가운데 전장 카드 + 오른쪽 현황·선택한 용병·유물 카드 + 아래 행동 줄(고용·배속·정지·메뉴·바로 시작·목표 메모) |
| B. 떠 있는 카드 (전장 전체 화면) | `b-floating-cards.png` | 전장을 화면 가득, 네 모서리에 반투명 크림 카드 — 왼쪽 위 웨이브·골드·몬스터, 그 아래 유물, 왼쪽 아래 팁, 오른쪽 위 선택한 용병, 오른쪽 아래 고용·버튼 / 가운데 위 둥근 웨이브 배너 |
| C. 모바일 세로 | `c-mobile.png` | 위 상태 카드 + 알약형 유물 줄, 아래 둥근 시트(큰 고용 버튼 · 선택한 용병 · 배속/정지/메뉴), 알약형 토스트 |

- 글꼴: 제목 고운바탕, 본문 고운돋움 (둘 다 OFL, `@fontsource`) — 게임에 넣으면 지금 픽셀 글꼴(Galmuri11) 대신/함께 쓸지 결정 필요
- 다시 그리기: 이 폴더에 `npm i @fontsource/gowun-batang @fontsource/gowun-dodum` 후 html 을 브라우저로 열기 (그림 파일 `field_crop.png`·`wide_game.png`·`tall_game.png`·`p_*.png` 는 저장소에 넣지 않음)
