UI 모션 시안 — 슬라이드 · ease-out

게임 안 UI 를 하나씩 살펴보고, 슬라이드나 ease-out 을 넣으면 좋아질 곳 12곳을 골랐어요. 카드마다 왼쪽이 지금 게임, 오른쪽이 제안이에요. 마음에 드는 번호를 알려 주시면 그것만 게임에 넣을게요.

  • 들어올 때 ease-out (빠르게 와서 부드럽게 멈춤)
  • 나갈 때 ease-in, 들어올 때보다 짧게
  • 이동 거리 6~24px — 도트 3px 격자에 맞춤
  • 배속·정지와 상관없이 실제 시간으로 재생
  • 전투 화면은 120~260ms, 로비·결과는 최대 400ms

추천 우선순위

  1. 자주 보이는 것부터 — ① 토스트 · ③ 용병 정보 시트 · ⑦ 골드 숫자 · ⑧ 성벽 체력 바 (전투 내내 보이는 곳)
  2. 한 번씩 크게 보이는 것 — ② 웨이브 배너 · ⑤ 유물 선택 · ⑥ ESC 메뉴 · ⑪ 결과 화면
  3. 로비 — ⑨ 건물 창 시트 · ⑩ 병영 탭 전환 · ⑫ 버튼 누름 (전 화면 공통)
