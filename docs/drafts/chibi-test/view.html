참고 그림에서는 '머리 위·양옆으로 크게 튀어나오는 실루엣'과 '선명한 머리색'만 빌렸어요. 몸 틀(두상 13×7 + 몸 13×6, 세로 1×2 눈, 팔 없음 + 둥근 손, 무기 왼쪽)은 지금 규칙 그대로예요.

② 고등급 광원 이펙트

이펙트 규칙(반투명·그라데이션 없음, 도트로만)에 맞춘 다섯 가지예요. 켜고 끄며 비교해 보세요. 추천 조합 — 레어: 테두리 빛 + 빛 입자 / 유니크: 후광 광선 + 빛 입자 + 반짝 스윕.

  • 테두리 빛왼쪽 위(빛 방향) 외곽선이 등급색으로 바뀌고 천천히 밝아졌다 어두워짐
  • 빛 입자발밑에서 1도트 빛 알갱이가 떠오름 (레어 2개 · 유니크 4개 + 반짝 별)
  • 후광 광선머리 뒤로 등급색 광선 8줄이 천천히 돎 (캐릭터 뒤 레이어)
  • 반짝 스윕2.4초마다 대각선 빛줄기가 몸을 훑고 지나감
  • 빛 기둥발밑 고리에서 점선 빛기둥이 솟았다 줄어듦 (가장 화려함 — 유니크 3성 전용 등으로)

③ 도끼·망치 실루엣 — 지금 vs 새 시안

검게 칠했을 때도 무엇인지 알 수 있게 머리 모양 자체를 다르게 했어요. 세로로 세운 그림이라, 게임에 넣을 때는 각도마다 다시 찍어요.
