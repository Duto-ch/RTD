# 3단계 — Figma 에서 오토 레이아웃 + 디자인 시스템

와이어프레임을 Figma 로 가져온 뒤 아래 값을 입힌다. 값은 지금 게임 코드(`src/ui/theme.js`, `src/ui/Hud.js`)와 같다 — 그래야 Figma 시안을 코드로 옮길 때 어긋나지 않는다.

## 프레임
- 세로 `HUD / Tall` 544x960, 가로 `HUD / Wide` 1280x720
- 전장 자리 사각형(세로 y 272~688)을 잠가 두고 그 위에 아무것도 놓지 않는다

## 글꼴 (Text Styles)
- 썬플라워(Sunflower) — 본문·버튼. 없는 기호는 고운돋움
- 크기: 웨이브 22 · 골드 22 · 체력 수치 16.5 · 이름 15 · 버튼 11~12 · 안내 줄 12 · 작은 글자 10~11

| 아이템 띠 | 가로 | — | 칸 26 안팎 |

| 상점 줄 | 가로 6칸 | — | 칸 사이 6 |

## Claude 에게 돌려줄 것
Figma 에서 확정한 프레임의 **간격·크기 숫자**(또는 Dev Mode 링크·스크린샷). Claude 가 `Hud.js` 의 `HUD` 배치 값으로 옮기고 `npm run check` + 화면 캡처로 맞는지 확인한다.
