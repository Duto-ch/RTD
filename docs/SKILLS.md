# 스킬 목록 (자동 생성 — `node tools/gen-skill-doc.mjs`)

모든 스킬은 쿨타임이 끝나면 자동 시전. 레벨 업(2~5) 때마다 해당 레벨 3종 중 1개 랜덤 습득.

속성 추가 효과 (피해를 주는 스킬): 레드 — 불꽃: 피해 +25% / 블루 — 서리: 20% 감속 1.2초 / 그린 — 가시: 2초간 초당 40% 피해
