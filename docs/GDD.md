# 용병단 디펜스 (Project RTD) — 기획 문서

## 장르 / 컨셉
- 랜덤 타워 디펜스 (RTD), 2D 픽셀아트, 세로 화면 (544x960, 모바일 우선)
- 성벽(5x5 필드) 위에 용병을 배치해, 성벽 주위를 도는 몬스터를 처치한다.

## 게임 진행 (사용자 원안)
1. 스테이지는 총 100 웨이브.
2. 용병 설치용 5x5 정사각형 필드 (성벽 이미지).
3. 몬스터는 필드 주변을 처치될 때까지 한 방향으로 계속 돈다. 필드에 100기가 쌓이면 게임 오버.
4. 1웨이브 40기 → 70웨이브까지 최대 200기로 증가 → 최종 웨이브까지 200기 고정.
5. 일정 시간이 지나면 자동으로 다음 웨이브. 5웨이브부터 10웨이브마다 정예 10기, 10웨이브마다 보스 출현.

## 성장 방식 (사용자 원안)
1. 몬스터 처치 골드로 용병 레벨 업.
2. 용병·몬스터 속성: 레드 / 블루 / 그린.
3. 상성: 블루 > 레드, 그린 > 블루, 레드 > 그린.
4. 속성별 용병 5종, 최고 5레벨.
5. 골드로 고용하면 랜덤 속성 + 해당 속성 영웅 5종 중 하나가 설치된다.
6. 같은 속성·같은 레벨 용병을 드래그해 다른 용병 위에 놓으면 (골드와 함께) 소비되고 대상이 레벨 업. 레벨마다 스킬 3종 중 1개 랜덤 획득.
7. 보스는 유물을 드랍하며, 유물은 필드 전체 용병에게 버프를 준다.

| 저격수 | 고화력 장거리 | 30 | 0.45 | 320 |

영웅 이름(임시): 레드 — 화염 궁수, 불꽃 마법사, 작열 저격수, 재의 주술사, 붉은 도적 / 블루 — 물결 궁수, 서리 마법사, 심해 저격수, 파도 주술사, 푸른 도적 / 그린 — 숲의 궁수, 대지 마법사, 덩굴 저격수, 바람 주술사, 초록 도적

## 스킬 (레벨 업 시 3종 중 1개)
- Lv2: 맹공(공격력+35%) / 속사(공속+30%) / 독수리 눈(사거리+20%)
- Lv3: 급소 노리기(치명+20%, 2.5배) / 다중 사격(대상+1) / 냉기(25% 감속)
- Lv4: 맹독(3초 독) / 폭발 화살(50% 범위) / 현상금 사냥(처치 골드+2)
- Lv5: 처형(12% 이하 즉사, 보스 제외) / 광란(공속+80%) / 속성 지배(불리 무시, 유리 2배)

## 유물 (보스 드랍)
전쟁의 북(공속+15%), 용사의 검(공격+20%), 매의 눈(사거리+15%), 황금 성배(골드+25%), 홍염/창해/녹림의 보주(해당 속성 공격+40%), 서리 왕관(몬스터 속도-10%), 용병 계약서(고용비-20%), 행운의 동전(치명+10%)
