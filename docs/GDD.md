# 용병단 디펜스 (Project RTD) — 기획 문서

> 전체 스킬 표: `docs/SKILLS.md` (데이터에서 자동 생성 — `node tools/gen-skill-doc.mjs`)

## 장르 / 컨셉
- 랜덤 타워 디펜스 (RTD), 2D 픽셀아트, 세로 화면 (544x960, 모바일 우선)
- 성벽(5x5 필드) 위에 용병을 배치해, 성벽 주위를 도는 몬스터를 처치한다.

## 게임 진행 (사용자 확정)
1. 총 100 웨이브.
2. 용병 설치용 5x5 정사각형 필드 (성벽 이미지).
3. 몬스터는 필드 주변을 처치될 때까지 한 방향으로 계속 돈다. 필드에 100기가 쌓이면 게임 오버.
4. 일반 몬스터: 1웨이브 40기 → 70웨이브까지 200기로 증가 → 이후 200기 고정.
5. 일정 시간마다 자동으로 다음 웨이브.
6. 정예 웨이브(5, 15 … 95): **일반 몬스터 + 정예 10기**.
7. 보스 웨이브(10, 20 … 100): **일반 몬스터 + 보스 1기**. 보스는 꽤 느리며, **성벽을 한 바퀴 다 돌면 즉시 게임 오버**.
8. **보스 디버프**: 보스는 1~2개의 디버프 능력을 랜덤 보유하고, 쿨타임마다 용병·영웅에게 건다 (공속 감소, 쿨타임 증가, 스킬 봉쇄 등).

## 성장 방식 (사용자 확정)
1. 몬스터 처치 골드로 용병을 고용·레벨 업.
2. 속성: 레드 / 블루 / 그린. 상성: 블루 > 레드, 그린 > 블루, 레드 > 그린.
3. **용병**: 속성별 5종 (총 15명), 1~5레벨. 고용 시 랜덤 속성 + 해당 속성 용병 5종 중 랜덤.
4. 같은 속성·같은 레벨 용병을 드래그해 다른 용병 위에 놓으면 (골드와 함께) 소비되고 대상이 레벨 업.
5. **용병마다 고유 스킬**: 2·3·4·5레벨 각각 3종 후보 → 레벨 업 시 그 레벨 후보 중 1개 랜덤 습득. **모든 스킬은 쿨타임마다 자동 시전.**
6. **영웅 승급**: 용병 → 영웅. 영웅은 속성별 3종 (총 9명), **마지막 5레벨 용병의 속성** 기준으로 3종 중 랜덤. 1~5레벨에 습득한 스킬 4개를 그대로 쓰고, **영웅 전용 고유 스킬 1개**를 추가로 얻는다.
7. 보스는 유물을 드랍하며, 유물은 필드 전체 용병에게 버프.
8. 이름: 영미권·북유럽권 이름의 한글 음차.
