## 2. 팔과 손

- **둥근 손·무기 레이어 방식은 모든 캐릭터의 공통 기준이다.** [확정 2026-11-17]
- **팔은 그리지 않는다.** 몸통 양옆은 외곽선으로 닫는다. [확정]
- **둥근 손 4×4**(외곽선 + 피부 2톤, 피부색은 캐릭터마다)이 몸에서 떨어져 떠 있다. [확정]
- **손은 몸통과 어느 정도 겹쳐도 된다** — 모든 캐릭터. 몸에서 너무 떨어져 보이면 안 된다. [확정]
- 무기를 쥔 손은 무기의 쥐는 점 위에 그린다. 무기가 몸 뒤로 넘어가는 순간(검을 젖힐 때)은 손도 몸 뒤. [현재 값]
- 두 손 무기(창): 두 손 모두 창대를 잡는다. 대기·회복 자세에서는 위쪽 손이 쥔 손보다 창끝 쪽, 찌르는 동안에는 뒤쪽. [현재 값]
- 빈손: 몸통 가장자리에 겹쳐 떠 있고 숨쉬기에 맞춰 흔들린다. 시전할 때는 들어 올린다. [현재 값]

## 3. 무기

- **몸과 따로 그린 레이어**를 손 위치에 얹는다. 무기마다 **쥐는 점(pivot)** 하나. [확정]
- **무기는 캐릭터 왼쪽(화면 왼쪽)**, 공격도 왼쪽을 향한다. 몸 그림은 뒤집지 않는다. [확정]
- **데포르메**: 날·머리·구슬을 크게, 손잡이는 짧게. 13×13 몸 옆에서 무기 실루엣이 먼저 읽히게. [확정]
- **무기가 몸통을 조금 가려도 된다** (베로나·엘린·아델 기준, 쥐는 손을 몸 쪽으로 붙임). [확정]
- **대기 때는 대각선으로 기울여 잡는다**: 활 −30°, 지팡이 25°, 창·검·도끼·단검 45° (바깥쪽으로 기울임). [확정 / 각도는 현재 값]
- **비스듬한 무기는 그림을 돌리지 않고 각도마다 새로 찍는다** (축을 따라 픽셀 → 외곽선). 그림 회전은 작은 도트가 뭉개진다. 창·단검 찌르기는 도트가 가장 깔끔한 0°·45°·90°만 쓴다. [확정 — 검·도끼·창·단검·지팡이 3종·활 모두 적용]
- **방패**: 무기 반대쪽(화면 오른쪽), 몸통과 겹치게, **쥔 손은 방패 뒤에 숨긴다**. [확정]

## 4. 애니메이션

**대기** — 8프레임 약 1.2초 반복 [현재 값]
- 숨쉬기: 내쉴 때 머리(머리/몸 나누는 줄 위쪽 전체)가 1px 내려앉음
- 무기·방패는 반 박자 늦게 따라 흔들림
- 눈 깜빡임 1번 (눈 윗줄 → 피부색, 아랫줄 → 감은 눈 선)
- 모자 끝(위쪽 몇 줄)은 따로 흔들림

**공격** — 프레임마다 길이가 다르다 [현재 값]
1. 예비 동작: 뒤로 젖힘 + 머리가 찌그러짐(1px) — 끝에서 약 200ms 멈춤
2. 휘두르기: 40~50ms 아주 짧게, 지나간 각도에 밝은 **잔상**
3. 타격: 무기 끝 **섬광** + 약 160ms 멈춤, 머리가 공격 방향으로 늘어나며 기움
4. 회복: 80~120ms 씩 천천히 대기 자세로

- **머리 기울기는 공격 방향과 같은 쪽**(젖힐 때 반대, 칠 때 공격 방향). [확정 — 아델 수정 요청]
- **공격의 마지막 프레임 = 대기 첫 프레임과 같은 자세**(무기 각도·두 손 위치). 대기 → 공격 → 대기가 끊김 없이. [확정 — 아델 수정 요청]
- 활: 당기며 뒤로 기댐 → 멈춤 → 놓는 순간 시위 튕김·몸 반동·화살 속도선. 시위를 잡은 손이 시위와 같이 움직인다
- 지팡이: 웅크림 → 들어 올림 → 구슬 섬광·고리 두 겹·불티
- 창: 뒤로 당김 → 쭉 찌르기(속도선) → 멈춤 → 45°로 회복

## 5. 사용자가 그린 몸 그림 넣기

- **24×24, 투명 배경 PNG**, 팔·손·무기는 그리지 않는다 (애니메이션이 따로 얹음). 예: `docs/drafts/char-13/edit/verona_body_v2.png`
- 넣을 때 그림마다 적어 두는 값: **머리/몸 나누는 줄**(베로나 v2 = 19), **눈 위치**(눈 윗줄 픽셀, 베로나 v2 = (9,15)·(13,15)), 모자 끝 줄 수, 쥐는 손·빈손 위치
- 몸 그림을 고치고 싶으면 지금 그림을 PNG 로 받아(`docs/drafts/char-13/edit/`) 고쳐서 다시 올린다

## 6. 결정 대기

- (해결 2026-11-18) 게임 화면 배율은 도트 1px = 화면 2px 로 적용, 104명 시트를 게임에 넣음 (`tools/import-roster-art.py`). 무기·손은 시트 안에 합쳐진 그림
- 그림이 왼쪽을 보므로 오른쪽 대상을 칠 때는 통째로 반전된다(무기도 오른쪽으로) — 바꾸고 싶으면 말할 것
