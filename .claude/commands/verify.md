AGENTS.md 의 "작업 루프" 3~4단계를 수행한다.

1. `npm run check` 를 실행한다 (단위 테스트 + 브라우저 테스트).
2. 실패한 테스트가 있으면 원인을 찾아 **게임 코드를 고친다**. 사용자가 확정한 규칙을 바꾼 게 아니라면 테스트를 고쳐서 통과시키지 않는다. 고친 뒤 1번으로 돌아간다. 같은 원인으로 3번 넘게 실패하면 멈추고 사용자에게 상황을 보고한다.
3. 모두 통과하면 `test-results/screens/` 의 스크린샷을 하나씩 열어 UI 겹침·잘림·빈 화면이 없는지 본다. 문제가 보이면 고치고 1번으로.
4. 결과를 짧게 보고한다: 통과한 테스트 수, 고친 내용, 확인한 화면.
